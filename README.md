## Objective

Estimate the prevalence of artemisinin-resistance (kelch13) and partner-drug or antifolate markers (crt, mdr1, dhfr) in *P. falciparum* from Benin using whole-genome sequencing data from ENA, classifying each sample as wild-type, mixed or mutant at every marker codon.

## Methods

- Reads capped to 5 million pairs per sample (seqtk, seed 42), mapped with bwa mem to the MalariaGEN Pf7 3D7 reference, duplicates marked (GATK MarkDuplicates); loci BAMs hold reads overlapping each gene +/- 2 kb. This stage ran in an earlier session; this notebook restores its saved output.
- HaplotypeCaller (haploid, gVCF) on the four loci; CombineGVCFs and GenotypeGVCFs; hard filters (QD < 2, FS > 60, SOR > 3, MQ < 40); SnpEff database Plasmodium_falciparum (contigs renamed 1-14 and back).
- Marker calls come from read counts at the whole codon: reads with MAPQ >= 20, base quality >= 20 at the three bases, not duplicates, one count per read pair. no_call if fewer than 10 reads; mutant if at least 80% of reads carry the mutant amino acid; mixed if at least 3 mutant reads and at least 10%; otherwise wild-type. Prevalence = samples with a mutant or mixed call among called samples, Wilson 95% confidence interval.
- Versions: GATK: The Genome Analysis Toolkit (GATK) v4.6.2.0; samtools: samtools 1.24; bcftools: bcftools 1.24; SnpEff: SnpEff	5.4c	2026-02-23

## Limitations

- 8 samples from one study give wide confidence intervals: 0 of 8 is compatible with a true prevalence up to about 32%.
- Reads were capped at 5 million pairs per sample; minor clones below about 10% of reads are not detectable.
- A haploid genotype call hides mixed infections; the marker calls above use read counts instead.
- Samples with weak coverage (median codon depth below 20): ERR15620828, ERR15630236.
- Markers called in fewer than 5 samples (interpret with caution): kelch13 P553L (n=2), kelch13 R561H (n=2), dhfr C59R (n=3).
- No copy-number analysis (for example mdr1 amplification) was done.
